2) 加权耗时口径（与赛题一致）

赛题补充材料《计时声明》：一次性工作（拓扑/符号分析、排序、GPU context 与显存分配、
首次 API 调用与 kernel 编译）按 0.005 系数计入；迭代工作（数值分解、回代求解）按 1.0 计入。

  加权耗时 = 0.005 x 一次性耗时 + 迭代耗时
  迭代耗时由自适应双 kernel 产出（见 3.1 节）：按每层 U(k,:) 对应列的平均填充长度
  选择「一 warp 一列」或「一 block 一列（行维切分）」两种更新内核。
  本表: 一次性 = SYM_ONLY 模式实测总耗时（含两次符号分析回退）；迭代 = 数值分解实测值
  13 矩阵加权总计 3675.4 ms，平均 282.7 ms
  注: GPU context 创建/首次调用无法在故障窗口内单独计量，该项亦按 0.005 计，影响可忽略。

3) GPU 利用率机理

  评分口径（2026-10-27 14:12 官方口径）: 循环求解阶段 GPU-Util >= 60% 得满分，未达按比例；
  显存带宽不单独评分，其分值已并入占用率（合计 10 分）。
  测量方法: ht-smi -l 100 -o <csv> --show-usage（10ms 级采样），只统计循环求解阶段，按时间加权。
  实测: ASIC_100k 约 29%（ht-smi 时间加权采样）
  机理: 每层 2 次 kernel 发射（div + upd），单次发射约 420 us（正常约 5 us）；
        ASIC_100k 共 1634 层 -> 约 3268 次发射，CPU 侧发射时间约 1373 ms，
        与数值分解总耗时 1377 ms 吻合 => CPU 发射瓶颈主导，GPU 空闲等待。
        各矩阵层数已实测（12 - 3729 层），层数越多发射开销越大。
