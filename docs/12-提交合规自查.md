## 仍然存在的三个风险（不是格式问题，是内容问题）

1. **纯 GPU 无回退 + 非确定性崩溃。**
   `local/ngspice` 现在是"A+ 单一路径、失败即返回非 0"。实测 GPU 二进制在个别用例上
   会段错误/挂死（`test_001` 5 次尝试 2 次成功）。任一用例崩 = 该用例 0 张表。
   建议至少做**同用例重试**（不是回落 CPU）。
2. **`ngspice.bin` 内部仍在回落 KLU。**
   本机 `hcSOLVER` 稀疏接口是 `mov w0,#9; ret` 空壳，所以日志里必然出现 `回落 KLU`。
   若评委按 A52/A64 查日志，"100/100"不能证明 GPU LU 真的执行过。
   正式环境若 hcSOLVER 可用则无此问题。
3. **`task2/out/` 未随包提交**，报告里的 286.59 s 在包内没有日志佐证，
   只能靠报告给的命令复跑。若允许，建议附一份 `task2/out/RUN_MODE.txt` + 计时日志。
